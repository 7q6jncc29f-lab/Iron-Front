IRON FRONT 1.0 — NORMANDY (experimental)

UPLOAD TO GITHUB
1. Unzip this project on the Mac.
2. Open your existing GitHub Iron-Front repository.
3. Use Add file > Upload files and drag all items INSIDE the unzipped folder, retaining the src and assets subfolders.
4. Commit. Main file MUST stay named index.html in the repository root.
5. Launch https://7q6jncc29f-lab.github.io/Iron-Front/?v=10 on iPhone Safari.

WHAT IS INCLUDED
- Working existing survival mechanics (weapons, waves, shooting, enemies, tanks, touch/gamepad input).
- Actual imported rigged soldier model and a selected animation clip from a separately hosted CC BY asset.
- Rendered procedural brick/plaster/stone surfaces on Normandy buildings.
- Project code in src, image icon in assets.
- Fallback model remains if external asset fails.

IMPORTANT LIMITATIONS
- Soldier model is MODERN military, not a historically accurate WWII German uniform; intended as a technical proof of integration. No historical claim.
- The imported model downloads over the network from GitHub each time, as well as Three.js from jsDelivr; this build is not offline capable.
- This is not AAA quality and not yet device-tested. No new detailed weapon mesh or true historic building model is included.
- Actual iPhone visual comparison and frame rate still require device testing.
